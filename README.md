## 🚀 Featured Projects

### 🔹 [SkillForge — Learning Management System](https://github.com/Dileepreddy-13/learning_management_system)
**Live Demo:** [skillforge-lac.vercel.app](https://skillforge-lac.vercel.app/)

- Built a responsive full-stack LMS enabling course browsing, enrollment, and real-time progress tracking, with secure authentication (Clerk/JWT) and Stripe payment integration.
- Designed RESTful APIs and MongoDB schemas supporting 1:few, 1:many, and many:many relationships for efficient management of users, courses, and progress data.
- Integrated Cloudinary for cloud-based media storage, externalizing 100% of image assets from MongoDB to reduce database overhead, and deployed on Vercel for scalable, seamless accessibility.

`React.js` `Node.js` `Express.js` `MongoDB`

<br/>

### 🔹 [Rentivo — Rental Listing Platform](https://github.com/Dileepreddy-13/Rentivo)
**Live Demo:** [rentivo.onrender.com](https://rentivo.onrender.com/listings)

- Developed a full-stack rental web application enabling users to browse, list, and manage properties, with secure authentication and authorization for creating, updating, and deleting listings and reviews.
- Integrated Cloudinary for cloud-based image storage and deployed on Render, ensuring scalable media handling and live accessibility.

`Node.js` `Express.js` `MongoDB`

<br/>

### 🔹 [Parking Lot Management System](https://github.com/Dileepreddy-13/Parking-Lot-management-)

- Designed a modular Parking Lot Management system using SOLID principles and the Strategy pattern, improving maintainability and reducing code changes for new features.
- Optimized spot allocation using queues and STL maps, achieving O(1) average-time complexity for entry/exit and reducing lookup time from O(n) to O(1) via license-plate-to-slot mapping.

`C++` `OOP` `DSA`
